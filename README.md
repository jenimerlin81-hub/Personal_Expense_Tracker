# Personal Expense Tracker with CSV

A beginner-friendly Python CLI application for recording, viewing, filtering, and summarizing daily expenses using CSV file storage.

## 📌 Project Overview

The Personal Expense Tracker allows users to maintain their daily expenses in a structured CSV file.

Users can add expenses with details such as date, category, description, and amount. The application also provides category-based filtering and summary statistics.

## ✨ Features

* Add daily expenses
* View all saved expenses
* Filter expenses by category
* Calculate category-wise expense totals
* Calculate total expenses
* Store data persistently in a CSV file
* Validate expense amounts
* Menu-driven command-line interface

## 🛠️ Technologies Used

* Python 3
* CSV Module
* File Handling
* Dictionaries
* Functions
* Loops
* Conditional Statements
* Exception Handling

## ▶️ How to Run

Check Python installation:

```bash
python --version
```

Run the application:

```bash
python expense_tracker.py
```
